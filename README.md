### 🏗️ Featured Engineering Projects

* **[TeamPilot](https://github.com/davidnicolini)** — Commercial management REST API built with **Java 25, Spring Boot 4, Spring Security, and PostgreSQL**. Features quote tracking, sales goal analytics, containerized environments with **Docker Compose**, and automated pipelines via **GitHub Actions CI/CD**.
* **[TaskHub](https://github.com/davidnicolini)** — Full-stack Kanban productivity platform powered by **Java 17, Spring Boot 3, PostgreSQL, and React (Vite)**. Implements stateless **JWT/BCrypt** authentication, **Apache Tika** document parsing, and LLM integration for intelligent task context.
* **[Hybrid Self-Hosted Infrastructure (davidnicolini.com.br)](https://davidnicolini.com.br)** — Bare-metal home server engineered on headless **Debian 13 (Trixie)** running **Docker, Nginx reverse proxy, and PostgreSQL**. Secured with hardened SSH (`PubkeyAuthentication`), UFW firewall, and zero-trust ingress via **Cloudflare Tunnels**.
* **[Multi-Distro Hyprland Dotfiles](https://github.com/davidnicolini/dotfiles)** — Automated Linux environment bootstrapper supporting **Arch, Debian, and Fedora** via **GNU Stow**. Features cross-distro package resolution, i18n localization, ShellCheck linting, and multi-OS matrix verification on GitHub Actions.
